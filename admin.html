Editorial workflow

  1. Draft in Markdown using the editor.
  2. Add tags (comma separated) for smarter filtering.
  3. Save to local storage. Export JSON for Git commits when ready.
  4. Need a backend? Hook postStore to an API later.

Posts persist locally. For GitHub Pages, commit the downloaded JSON to data/posts.json.
